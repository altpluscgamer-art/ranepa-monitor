# Мониторинг сервисов РАНХиГС

Локальный монитор доступности 19 внутренних сервисов академии. Работает на
Windows с обычным PowerShell 5.1, **без прав администратора** и без установки
Python. Проверки идут по расписанию каждые 5 минут через Планировщик задач,
результаты — на локальной странице http://localhost:8765/, в истории CSV,
в автоотчёте «система × часы» и в журнале событий.

> Подробная пользовательская инструкция — в `README_FIRST.txt`.

## Возможности (версия R8.18)

- Проверка «снаружи»: HTTP-запрос без учётных данных, уровни достоверности —
  сеть → валидный HTTP → маркеры страницы входа → (опционально) реальная авторизация.
- Страница с таблицей, спарклайнами за 6 часов, картой доступности
  (19 строк × 24 клетки по 15 минут), длительностью проблем
  («проблема: 47 мин (с 09:12)») и расшифровкой HTTP-кодов в легенде.
- Кнопки: «Проверить сейчас», ⟳ у каждого сервиса (отдельный столбец),
  «Обновление страницы» (выкл/1–60 мин, выбор запоминается), звук вкл/выкл,
  «тихо на час», тема (авто/тёмная/светлая, в «авто» тёмная включается 22:00–07:00).
- Звук при новых падениях (WebAudio) и системный сигнал из Планировщика;
  тихие часы 22:00–08:00 для системного сигнала; мигающий заголовок и
  динамический favicon с числом недоступных сервисов.
- История за день в `services_history_ГГГГ-ММ-ДД.csv` (+автоархивация старше
  7 дней в `services_history_archive.zip`), журнал событий
  `monitor_events_ГГГГ-ММ-ДД.log`.
- Автоотчёт в формате «Мониторинг систем 2.0» (`monitoring_report_ГГГГ-ММ-ДД.csv`):
  система × часы 00:00–23:00, в часе — **худший** вердикт, успехи копятся
  флагами («Доступность +; Авторизация +»).
- Контакты сервис-менеджеров в таблице (несколько человек — на разных строках).
- Опциональная проверка авторизации раз в час (`-AuthCheck`): креды только
  локально, зашифрованные DPAPI, через `setup_creds.ps1`. Пароли в репозиторий
  **не попадают** (см. `.gitignore`).

## Быстрый старт

1. Запустить `INSTALL.bat` (двойной клик) → подтвердить Y.
   Он скопирует файлы в `%LOCALAPPDATA%\RanepaMonitor`, снимет блокировку
   Zone.Identifier, создаст задачи Планировщика (проверка каждые 5 мин,
   авто-логин раз в час), ключ автозапуска и ярлык-виджет на рабочем столе.
2. Открыть http://localhost:8765/ (или ярлык «Monitoring RANEPA»).
3. Выбрать в «Обновление страницы» период, например 5 мин.
4. Остановить всё: `stop_monitor.bat` или кнопка «Остановить мониторинг».

## Где лежат данные (после установки)

```
%LOCALAPPDATA%\RanepaMonitor\
    services_history_ГГГГ-ММ-ДД.csv   — история проверок (разделитель «;»)
    monitoring_report_ГГГГ-ММ-ДД.csv  — автоотчёт «система × часы»
    monitor_events_ГГГГ-ММ-ДД.log     — журнал событий (проверки, тревоги)
    last_state.txt                    — память «новых проблем» (для звука)
    services_history_archive.zip      — архив старше 7 дней
```

## Структура репозитория

| Файл | Назначение |
|---|---|
| `monitor_services.ps1` | сам монитор (все режимы: разовый, сервер, авто-логин) |
| `INSTALL.bat` | установка одним запуском |
| `run_monitor.bat` / `stop_monitor.bat` | запуск/остановка (пересоздают расписание) |
| `make_widget.bat` | ярлык-виджет «Monitoring RANEPA» на рабочем столе |
| `setup_creds.ps1` | шифрование учётных данных через DPAPI |
| `auth_config.csv` | конфиг авто-логина (только заголовок по умолчанию) |
| `ranepa-monitor-ext/` | браузерное расширение v2.1 (попап + бейдж + график), опционально |
| `README_FIRST.txt` | подробная инструкция для дежурного |
| `CHANGELOG.md` | история версий R3 → R8.18 |

## Безопасность

- Репозиторий держите **закрытым** (private): в списке сервисов — внутренние
  адреса и контакты дежурных.
- Никогда не коммитьте `auth_creds/` (шифрованные пароли), сами пароли
  и файлы xlsx с учётками. Это закрыто в `.gitignore`.
- Пароли из старого Excel сменить и хранить только через `setup_creds.ps1`.
