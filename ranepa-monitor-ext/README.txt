РАСШИРЕНИЕ "МОНИТОРИНГ СЕРВИСОВ РАНХиГС" — версия 2.0

НОВОЕ В v2.0
- Кнопка перезагрузки у КАЖДОГО сервиса в попапе — точечная проверка
  одного сервиса через /check (требует на сервере R8.6 или новее).
- Показ времени ответа (мс) у каждого сервиса.
- Кнопка "Обновить" в попапе.

УСТАНОВКА — БЕЗ ПРАВ АДМИНИСТРАТОРА
1. Откройте в адресной строке:  browser://extensions
2. В правом верхнем углу включите "Режим разработчика".
3. Нажмите "Загрузить распакованное расширение".
4. Выберите ПАПКУ ranepa-monitor-ext (в которой лежит manifest.json).
5. Закрепите значок: иконка "пазл" рядом с адресной строкой.
Если пункта нет — расширение заблокировано политикой организации.

ЧТО ОНО ДЕЛАЕТ
- Раз в 2 минуты читает статус с локального монитора (localhost:8765).
- Значок: красный с числом = сервисы недоступны; жёлтый = 4xx;
  зелёный без числа = всё в порядке; серый "?" = монитор не запущен.
- Клик по значку — таблица всех сервисов с кодом, временем ответа
  и кнопкой точечной проверки у каждой строки.

ВАЖНО
- Сами проверки делает Планировщик Windows (скрыто, каждые 5 минут).
- Расширение живёт, пока запущен браузер.
